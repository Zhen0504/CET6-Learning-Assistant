## 📖 项目简介

CET6-Learning-Assistant 是一套覆盖 CET-6 主要训练场景的本地学习工具。

项目目前包括：

- 听力专项训练
- 选词填空
- 长篇阅读
- 仔细阅读
- 翻译
- 写作
- 精读训练
- 自由学习工具

其中写作与翻译模块进一步加入了长期学习追踪系统，使训练流程从：

```text
出题
→ 做题
→ 评分
```

扩展为：

```text
出题
→ 做题
→ AI 评分
→ 自动记录
→ 历史比较
→ 高频弱项统计
→ 原错句复训
→ 同类迁移训练
→ 间隔复习
→ 长期能力追踪
```

所有 AI 应用采用：

```text
Python + Flask
        ↓
DeepSeek API
        ↓
HTML / CSS / Vanilla JavaScript
```

API Key 仅保存在服务端 `.env` 中，不发送给浏览器，也不会提交到 Git 仓库。

## 🌐 翻译训练

翻译模块用于 CET-6 段落汉译英训练。

基本流程：

```text
AI 生成中文原文
→ 用户翻译
→ AI 评分
→ 参考译文与难点解析
```

评分维度包括：

- 准确性
- 流畅性
- 术语运用
- 语法句式

### 学习历史

每次成功评分后都会自动保存：

- 总分
- 各分项得分
- 用户译文
- 原文
- AI 反馈
- 结构化错误
- 下一阶段重点

并自动比较：

```text
本次
vs
上一次
```

包括：

- 总分变化
- 分项变化
- 连续出现的问题
- 本次新问题
- 本次未再出现的问题

### 错句复训

AI 会从真实历史记录中提取出现问题的中文句子。

例如：

```text
在一些偏远地区，农村电商帮助当地农民销售产品，
既增加了收入，也缩小了城乡数字差距。
```

如果用户之前把“缩小”误译成“扩大”，系统会保存该错误所在的**完整中文原句**。

复训流程：

```text
真实原错句
↓
重新翻译
↓
AI 单句评分
↓
原句通过
↓
生成 2 道相同能力、不同内容的迁移句
↓
完成迁移训练
↓
判断本轮是否真正通过
```

系统不会仅依赖 AI 返回的错误短语。

如果 AI 定位到：

```text
既增加了收入，也缩小了城乡数字差距
```

后端会根据原文句界恢复成完整原句后再进入复训。

## ✍️ 写作训练

写作模块模拟 CET-6 写作训练。

支持：

- 给定主题
- AI 随机命题
- 指定首句展开
- 150–200 词目标
- 30 分钟倒计时
- 14 档 AI 评分

评价维度包括：

- 切题与论点
- 结构与连贯
- 词汇
- 语法句式

### 写作思路参考

AI 生成题目后会提供写作思路。

为避免训练过程中产生过多提示依赖：

```text
写作思路参考
```

默认保持折叠。

用户需要时可以手动展开。

### 写作错误复训

评分后 AI 会把能够定位到原作文的错误句保存下来。

例如：

```text
AI tools provides students with quick access to information.
```

系统会让用户重新改写原句，而不是只阅读文字反馈。

原句通过以后，再生成同能力迁移训练，例如：

```text
主谓一致
冠词
时态
非谓语
搭配
句子结构
```

如果同一个原句存在多个独立问题，可以分别记录多个错误标签。

## 📊 学习分析

写作和翻译均提供：

```text
📊 学习分析
```

页面。

主要包括：

- 总练习次数
- 当前待复训数量
- 学习中错句数量
- 已掌握错句数量
- 最近成绩变化
- 各分项变化
- 高频错误
- 长期弱项
- 历史学习记录

### 少量记录

只有 1 次记录时：

```text
显示当前分数摘要
不推断趋势
```

只有 2 次记录时：

```text
显示上次 / 本次 / 变化
不推断长期趋势
```

达到 3 次及以上后才开始绘制趋势图。

达到至少 6 次训练后，系统可以比较：

```text
前 3 次平均
vs
最近 3 次平均
```

避免使用少量数据制造虚假的“进步趋势”。

## 🔁 间隔复习机制

新的错句默认在次日进入正式复习。

阶段安排：

```text
新错句
↓
D+1

第一次完整通过
↓
D+3

第二次完整通过
↓
D+7

第三次完整通过
↓
已掌握
```

如果复训失败：

```text
阶段至少退一级
↓
次日继续复习
```

用户可以提前练习还没到期的错题，但：

> 提前练习不会推进正式的间隔复习阶段。

这样可以避免刚看完正确答案后立即重做造成的“假掌握”。

### 环境要求

推荐：

```text
Python 3.8+
Chrome / Edge
DeepSeek API Key
```

Windows 用户可以使用项目根目录中的一键启动脚本启动已经配置好的写作和翻译模块。

### 普通启动方式

进入任一模块，例如翻译：

```bash
cd 翻译
```

安装依赖：

```bash
pip install -r requirements.txt
```

复制环境变量模板：

Windows：

```bash
copy .env.example .env
```

macOS / Linux：

```bash
cp .env.example .env
```

然后编辑：

```text
.env
```

填写：

```text
DEEPSEEK_API_KEY=你的API_KEY
```

启动：

```bash
python app.py
```

浏览器访问：

```text
翻译：http://127.0.0.1:5559
写作：http://127.0.0.1:5560
```
